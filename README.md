# Windows 11 — интерактивный симулятор рабочего стола

Демо-интерфейс в стиле Windows 11, работающий прямо в браузере без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173
```

## Возможности

- Рабочий стол с ярлыками, меню «Пуск», поиском, календарём и быстрыми настройками.
- Окна приложений можно перетаскивать, сворачивать, разворачивать и закрывать.
- Проводник, демонстрационный Edge, блокнот с автосохранением, калькулятор, параметры и другие окна.
- Адаптация под узкие экраны.

Это визуальная симуляция: браузер и системные параметры не подключаются к настоящим сайтам и настройкам компьютера.
