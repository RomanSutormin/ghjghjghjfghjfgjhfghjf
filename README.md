# Локальный рабочий стол в стиле Windows

Это веб-приложение с интерфейсом рабочего стола, **не эмулятор Windows**. Удалены демо-погода, вымышленные диски и файлы, а также переключатели, которые не могли управлять устройством.

## Запуск

На Windows распакуйте архив и запустите `start-windows.bat`. Он поднимет сервер только на `127.0.0.1` на свободном порту и откроет страницу в браузере. Нужен Python 3; остановка — `Ctrl+C` в открывшемся окне. На macOS/Linux запустите `python3 run_local.py`. Используйте актуальный Chrome или Edge: безопасный локальный контекст нужен браузеру для доступа к выбранной папке.

## Реальные возможности

- **Файлы:** пользователь выбирает папку и явно выдаёт браузеру доступ к ней. Можно просматривать её содержимое, заходить в подпапки, создавать файлы и папки, копировать выбранный файл в открытую папку и искать по именам в текущей папке. Перезапись существующего файла требует подтверждения. Удаления нет.
- **Блокнот:** редактирует выбранный текстовый файл и сохраняет изменения в него. Поддерживает открытие и сохранение файлов через диалоги браузера; черновик хранится в `localStorage` этого сайта.
- **Калькулятор:** выполняет арифметические операции и показывает ошибку при недопустимом результате.
- **Интернет:** открывает настоящий сайт в новой вкладке.
- **Сведения и статус:** используют только данные, сообщённые браузером. Папки, системные параметры, сетевые настройки и погода не выдумываются.
- Активные форматы вроде SVG не запускаются как веб-страницы из файловой папки; неподдерживаемые для безопасного просмотра файлы скачиваются.

Файлы обрабатываются в браузере; приложение не отправляет выбранные файлы на свой сервер. Разрешение на папку действует в текущей вкладке и не переживает её перезагрузку. Браузер не может запускать произвольные приложения, читать диск без разрешения, управлять Wi-Fi или громкостью, менять настройки ОС и выключать компьютер. Для этого нужна отдельная нативная программа с системными разрешениями.

## Проверки качества

```bash
npm install
npm run check
npm test
npm audit --audit-level=high
```

Тесты используют имитацию File System Access API в jsdom и проверяют реальные сценарии приложения: разрешения, навигацию по папкам, создание/импорт/сохранение файлов, защиту от случайной перезаписи, калькулятор, окна и обработку опасных форматов. Они не заменяют ручную проверку настоящего диалога выбора файлов в Chrome/Edge. Axe проверяет правила WCAG A/AA для структуры и доступных имён; контраст дополнительно проверяется отдельным тестом на основных текстах белых панелей.
